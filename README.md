# VibeCode Asset Studio Audit Mirror

This public repository is a metadata and reporting mirror for VibeCode Asset Studio. It contains task reports, QA reports, audit decisions, commit/branch identifiers, test summaries, artifact hashes, and known limitations.

Canonical source: `LightDucan/VibeCode-Asset-Studio` (private).

The audit mirror intentionally excludes production source code, tests, prompts, character images, generated frames, videos, model weights, credentials, tokens, `.env` files, and private project workspace contents. Snapshots are exported by the canonical repository's fail-closed audit exporter and contain no source diff contents.
